### 实现结构（与竞技场同构）
- `assets/resource/pipeline/gym.json` 9 节点：`Gym_Enter` / `Gym_Router` /
  `Gym_Wait`(post_delay 250) / `Gym_Back` / `Gym_Home` / `Gym_Page` / `Gym_Pick` /
  `Gym_Result` / `Gym_Fight`。流程节点 next 全回 `Gym_Router`。
- `assets/agent/gym_actions.py` 5 个动作：`GymRouter` / `GymHome` / `GymPage` /
  `GymPick` / `GymResult`。判页优先级
  **fight > result > pick > wait > page > home > unknown**。
- 判页阈值统一 0.65（VS/选人 用 0.85 类），ROI 见 `GymRouter.DEFAULTS`。
- `unknown_back_s = 25`（不是竞技场的 5s）——VS 倒计时 16s + 加载，5s 会误点。
- 道馆选择做成 interface option「道馆选择」5 个 case（含「不切换」`[0,0]`）。
- 任务 `gym_challenge`，无限循环。

### 两个坑（都是实测踩出来的）
1. **结算关闭后的残余帧会被判成战斗**：`GymResult` 点完空白只等 800ms，
   1~2s 后血条还在淡出，Router 判 fight 就去打空气。
   修法：`_wait_vanish()` 轮询等 `gym_close` 消失（实测 1.5~2.2s，上限 4s）
   + `tail_s 0.8` 等角色展示起来，再交回 Router。
2. **「点完页面不变」必然被连点**：匹配按钮、选人卡位点完画面都不变。
   `GymPage.cooldown_s=40`、`GymPick`/`GymHome` 各自 cooldown。
   选人点前必须先查 `gym_pickwait`，否则第二次点会把已选角色 toggle 掉。
