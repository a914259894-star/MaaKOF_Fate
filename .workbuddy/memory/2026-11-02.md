用户发现 maaCQDiamond 关掉实时画面后非常流畅，要求本项目也默认关，且发版后保持关闭。

- 参考实现：`D:/Projects/maaCQDiamond/tools/config_seed.py`（v2.0.26）。它在打包末尾把
  `UseSeparateScreenshotTasker=false`、`UI.LiveView.EnableLiveView=false` 合并进
  发布包 `config/config.json`。本项目按同样做法移植。
- **版本差异（重要）**：本项目 `.github/workflows/install.yml` 固定 `MFAA_VERSION: "v2.5.7"`，
  maaCQDiamond 是 `""`（latest，实机 v2.16.4）。v2.5.7 把全局键和 `Instance.default.*`
  放在同一个 `config/config.json`；v2.16.x 拆成 `config/config.json` + `config/instances/*.json`。
  已验证 v2.5.7 的 `libs/MFAAvalonia.Core.dll`（2.5MB，真正逻辑在这里，237KB 的
  `MFAAvalonia.dll` 是壳）**含** `UI.LiveView.EnableLiveView`、`UI.LiveView.RefreshRate`、
  `UseSeparateScreenshotTasker`，且与 `UI.MainWindow.Width` 出现在同一张全局键表里
  （偏移 2511800 附近的字符串序列），所以写顶层全局 config.json 有效。
  搜 .NET DLL 字符串要用 UTF-16LE，ASCII grep 搜不到。

## 远程窥视 release 包内容（省流量）

下载 187MB 只为看一个 86 字节的配置不值得。做法：`io.RawIOBase` 实现
`read/readinto/seek/tell`，用 HTTP `Range` 请求取字节，喂给 `zipfile.ZipFile(BufferedReader)`，
然后 `z.read("config/config.json")`。注意 **`readinto` 必须实现**，否则 zipfile 报
`NotImplementedError`。脚本在 `C:/Users/91425/AppData/Local/Temp/peek_zip.py`。
